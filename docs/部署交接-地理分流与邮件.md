## 4. 部署配置（关键变更）

> 之前 `from` 用 `noreply@resend.dev` 是验证前临时方案（必进垃圾箱）。域名已验证，**两台服务器的 `server.local.json` smtp 块必须改成**：

```json
"smtp": {
  "enabled": true,
  "host": "smtp.resend.com",
  "port": 587,
  "user": "resend",
  "pass": "${SMTP_PASS}",
  "from": "DocuChat <noreply@sship.online>",
  "publicBaseUrl": "https://www.sship.online"
}
```

- `SMTP_PASS` 环境变量 = SMTP key（`re_eCZ...` 那个），经 `deploy-ecs.sh` / systemd 注入
- `publicBaseUrl` 用 `https://www.sship.online`（Worker 分流入口，重置链接会 302 到 cn/glb 并保留 path）

**其余部署要点**：
- 本机编译 musl：`export PROTOC="$PWD/.tools/protoc/bin/protoc"`，linker `~/.local/musl/bin/musl-gcc`（`.cargo/config.toml` 已配）
- 两台都跑 `deploy-ecs.sh`（腾讯 li 用户写 systemd 要 sudo）
- 服务器 wiki 数据（llm_wiki_projects）不要动
- 部署完验证：health、`/register` 页面、真实邮箱注册收验证邮件、`forgot-password` 收重置邮件、`journalctl` 无 "SMTP not configured"
