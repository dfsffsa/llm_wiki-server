## 4. 关键注意事项（上一会话踩过的坑）

| 事项 | 说明 |
|------|------|
| **upstream 子模块 dirty 是正常的** | `apply-patches.sh` 后的状态；**不要提交子模块指针** |
| **server 编译慢（LTO）** | release profile `-C lto` + `codegen-units=1`，改 1 行 server 源码也要 **7-10 分钟**重链接。多次 server 改动攒批一次编译；纯前端改动（overlay/static）用旧二进制即可实测 |
| **静态文件缓存 1h** | 除 i18n.js（已 no-cache）外，静态文件 `Cache-Control: max-age=3600`。改 landing HTML 等要等缓存过期才生效 |
| **改文案只改 i18n.js** | 文案唯一源在 `overlay/static/i18n.js` 的 `COPY` 字典；改品牌名/slogan/按钮 = 改对应 key 一行，刷新即生效（见 docs/国际化-i18n.md §2） |
| **lite 是构建产物** | 改 `overlay/static/lite/` 后必须 `build-web.sh` 才进部署 |
| **密钥不硬编码** | LLM key / SMTP_PASS 走占位符注入 `server.local.json`（chmod 600）；脚本只读 env |
| **wiki 数据不在 repo** | 在 `~/overseas-github/llm_wiki_projects/` |
| **双服务器 SSH 不同** | ecs99（阿里云）：端口 22022、root；ecs199（腾讯）：li 用户无 sudo，`SKIP_SYSTEMD=1` 手动装 unit |
